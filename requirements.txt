# Phase 0 pinned environment. Verified on Windows 11, Python 3.12.4,
# RTX 4050 Laptop 6 GB, driver 581.86, on 2026-09-15.
#
# This stack breaks across minor versions, so every version is pinned, including
# transitive ones. Verify any change with: python scripts/check_env.py
#
# INSTALL (two commands, in this order):
#
#   pip install -r requirements.txt
#   pip install --no-deps robomimic==0.3.0
#
# robomimic must be installed with --no-deps because it requires egl_probe, which
# compiles against EGL headers and cannot be built on Windows. Its real
# dependencies are pinned below, and src/envs/robosuite_compat.py registers an
# egl_probe stub at runtime. `pip check` will report the missing requirement; that
# is expected. See docs/phase-0/result.md.
#
# Pin rationale for the versions that are not simply "latest":
#   mujoco==3.1.6    3.13 renamed MjData.qM to M; robosuite 1.4.1 uses the old name
#   robosuite==1.4.1 robomimic 0.3.0 is the last release and pairs with 1.4.x.
#                    robosuite 1.5.x changed the controller API, which would put
#                    Phase 3 dataset replay fidelity at risk
#   numpy==2.2.6     lerobot requires >=2.0,<2.3. robosuite 1.4.1 was verified
#                    working under it
#
# Known and accepted: opencv-python (robosuite) and opencv-python-headless
# (lerobot) are both present and provide the same `cv2` namespace. The headless
# build wins and is the correct one for offscreen work. Left alone deliberately --
# uninstalling either one removes shared files and breaks both.
